担当パート（ユーザー機能 / ログイン・会員登録）

本プロジェクトにおいて、ユーザー認証関連ページ（ログイン・会員登録UI）のフロントエンド設計および実装を担当しました。

---

1. ログインページ（login）

ユーザーのログイン機能UIおよび基本的な入力バリデーション処理を実装しました。

主な機能
- メールアドレス入力フィールド
- パスワード入力フィールド
- エラーメッセージ表示UI
- 「ID保存」チェックボックス機能
- ログインボタンUI設計
- パスワード再設定モーダルUI実装（仮機能）


2. 会員登録ページ（sign up）

ユーザー登録フォームのUIおよび入力構造を設計・実装しました。

主な機能
- メールアドレス入力
- パスワード / パスワード確認入力
- パスワード表示切替ボタン（トグル）
- ニックネーム入力
- 生年月日入力
- 性別選択ボタン（男性 / 女性）
- 個人情報同意チェックボックス
- 会員登録ボタンUI


3. 共通機能・工夫点

- jQueryを利用したDOM操作およびイベント処理
- common.js / util.js を活用したコード分割構造
- header / footerの共通コンポーネント分離構造を適用
- ユーザー体験を意識した入力UI設計

学んだこと・感じたこと

本プロジェクト（イチタビ）を通して、初めてユーザー側のバックエンドコードにも触れる経験をしました。
最初は非常に難しく、エラーや不明点も多くあり、周囲の助けを借りながら進める場面も多かったです。

しかし、その中でも試行錯誤を重ねて最終的にプロジェクトを完成させることができ、大きな達成感と成長を実感しました。
